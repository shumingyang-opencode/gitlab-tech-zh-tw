為什麼學 GitLab？

你八成用過 GitHub——而 GitLab 是它的「另一種答案」：把版本控制、CI/CD、容器登錄庫、 監控、Pages、Wiki 全部內建在一個產品，而且可以自架在自家伺服器。 學會 GitLab，等於學會「完整的 DevOps 平台該長什麼樣」。

這站也特別安排了一章詳細比較：術語差異、託管模式、CI/CD 設計哲學、 開源程度與價格——讓你在 GitHub 與 GitLab 之間做出知情選擇。

立即體驗：GitLab 術語 vs GitHub 術語

GitHub · 你可能已熟悉
Repository（repo）
Pull Request（PR）
Organization
GitHub Actions
GitLab · 對應術語
Project（專案）
Merge Request（MR）
Group（群組）
GitLab CI/CD
一句話：GitLab 的「Merge Request」就是 GitHub 的「Pull Request」—— 概念相同，名字不同。完整對照見單元 8。

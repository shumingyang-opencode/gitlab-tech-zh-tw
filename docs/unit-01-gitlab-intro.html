一句話定義

GitLab 是一個一體化的 DevOps 平台——它把程式碼託管、Merge Request、 Issues、CI/CD、容器登錄庫、Pages、Wiki、監控全部內建在一個產品， 並提供 GitLab.com（雲端）與自架（Self-managed）兩種使用方式。

GitLab.com · 雲端
註冊帳號即可用
gitlab.com/USER/專案
自架 · Self-managed
安裝在自家伺服器
gitlab.example.com/專案
程式碼與 CI 都在公司內
最大特色：GitLab 是少數可以完全自架的主流平台—— 這是它與 GitHub 最根本的差異（詳細比較見單元 8）。

版本：CE / EE / GitLab.com

版本說明
GitLab CE社群版（Community Edition），開源、免費、可自架
GitLab EE企業版（Enterprise Edition），加付費功能（approval rules、audit 等）
GitLab.com官方 SaaS——免費額度可用，進階功能需付費方案
重點：CE 是完整開源（MIT 授權），任何人都能下載、安裝、改寫—— 這在「閉源的 GitHub」面前是獨特的存在。

與 Git / GitHub 的關係

  • Git：底層版本控制工具，跟 GitHub / GitLab 都無關。
  • GitLab 與 GitHub：都是「建在 Git 之上的平台」，功能大量重疊。
  • 核心差別在哲學：GitHub 專注「程式碼社群與生態」；GitLab 專注「一體化 DevOps 與自架」。

帳號與認證

與 GitHub 類似，可用 HTTPS + Personal Access Token（GitLab 也稱 PAT）或 SSH key 連線；另有 glab（GitLab CLI，對應 GitHub 的 gh）。

認證方式 · AUTH
HTTPS + Personal Access Token   # 最常見
SSH key                          # 免密碼
glab auth login                  # GitLab CLI（類比 gh）
安全：Token 不要提交進 repo；設好權限範圍（scope）、有期限；洩漏立即撤銷。

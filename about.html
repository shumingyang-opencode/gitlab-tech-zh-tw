這個網站是什麼

一份把 GitLab 平台從平台概念、第一個專案，教到 CI/CD、Pages， 並與 GitHub 詳細比較的繁體中文教學網站。目標讀者是初階工程師與學生—— 你可能已熟悉 GitHub，想認識「另一種 DevOps 平台」。

本站採用中英對照：中文解說為主，技術名詞與指令保留英文， 讓你同時學會「怎麼做」與「怎麼說」。

為什麼要學 GitLab

  • 少數能完全自架的 DevOps 平台——程式碼與 CI/CD 都留在自家。
  • 一體化設計：從 Issue 到部署同一套產品。
  • 認識「GitHub 之外的世界」，懂得比較與選型。

本站建置

  • 決定主題與課程大綱（8 單元、中英對照、含 GitLab vs GitHub 比較專章）
  • 承襲既有教學站的深色 × 霓虹設計語言與架構慣例
  • 建立首頁、概念地圖、學習路線與單元教學架構
  • 逐單元撰寫內容，持續擴充與修正
